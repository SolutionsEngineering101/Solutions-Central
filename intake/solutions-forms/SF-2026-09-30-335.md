# Solution Request #335 - Nusummit Technologies
**Date:** 2026-09-30  |  **Status:** Pending Update  |  **Complexity:** Not Set

## Brief
We would like to check the feasibility of a UI/reporting enhancement in the To-Do List → My Approvals section.
Currently, when an Approver views the nominations under the My Approvals tab, the Recipient Name and Country are displayed together in the same column.
The same format is retained when the nominations are downloaded as a PDF or CSV, where the recipient’s name and country appear in a single column.
The client has requested that, for better clarity and readability, we either:
Remove the Country from this field, if it is not essential; or
Display the Country in a separate column from the Recipient Name.
Could you please check the feasibility of implementing either of the above options and advise on the recommended approach?
