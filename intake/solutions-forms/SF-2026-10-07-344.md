# Solution Request #344 - Restore Datashred
**Date:** 2026-10-07  |  **Status:** Solution Given Closed  |  **Complexity:** Not Set

## Subject
Solution Request : 344344 : Gift Card Availability Visibility

## Brief
Gift Cards, when unavailable, should just not show up instead of throwing the last-minute error message

## Problem Description
This is from th VVR session done by Anurup. The point Poc made here is that few gift cards are unavailable in the redeem page and that is only known after reaching the last step of redemption. If the platform can delete the gift cards which are not available or at least display a disclaimer text that gift cards might be unavailable for some time. This happens in case of Amazon, Myntra, and Flipkart in India. If something similar can be replicated for UK.

## Solution Given
Live availability is not something our vendors provide : We source gift vouchers from several fulfilment partners. Apart from one, none of them send us live stock or availability updates. So for almost all of the catalogue, the platform has nothing reliable to grey out or hide at step 1. If we built that process on the one vendor that does share stock, it would cover only a small part of the catalogue. Employees would then see some vouchers flagged and others not, and that inconsistency would be more confusing than the current experience.

Our partners commit to keeping the catalogue redeemable : Every voucher on the platform is listed because the partner has committed to fulfilling it. A failed redemption is an exception, not something employees should expect. Hiding or greying out vouchers in advance would treat those exceptions as normal and would shrink a catalogue that is available nearly all of the time.

The platform already protects employees when a voucher keeps failing : When a gift voucher fails at redemption three times, the platform automatically greys it out so that other employees can't select it.
