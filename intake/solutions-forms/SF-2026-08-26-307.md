# Solution Request #307 - SBFC Finance Ltd.
**Date:** 2026-08-26  |  **Status:** Unknown  |  **Complexity:** Not Set

## Brief
1. Approval workflow for bulk point uploads (For Redemption only client)

The client wants to give Zonal Managers independent access to upload bulk point files for contests/initiatives within their respective teams. However, the points should only be distributed after an appropriate review/approval.

Proposed workflow:
Zonal Manager uploads file → HR Admin/authorized approver reviews the employee-wise allocation → approver approves → points are credited to employee wallets.

The objective is to create a fair and transparent approval layer, ensuring that managers cannot repeatedly allocate points to the same employees without oversight.

Could you please confirm:

- Can this maker-checker/approval workflow be configured on the platform?
- Can Zonal Managers have upload access without having final approval/distribution rights?
- Can we configure multiple approvers, where any one of the designated approvers can review and approve the file?
- If the designated approver is unavailable/out of office, is there a delegation option where they can temporarily delegate their approval authority to another user for a defined period?
- If delegation is supported, can the delegate approve the files submitted by Zonal Managers during that period?

2. Bulk point revocation

If an incorrect/mistaken bulk file is uploaded and points are distributed incorrectly, can an admin revoke those points in bulk directly from the platform/admin dashboard?

If this is not available as a self-service capability, would the revocation need to be handled by our backend/operations team? Please also confirm what information would be required to process such a request.

Please share the recommended platform workflow/capabilities for both scenarios so I can provide the client with an accurate response.

3. Merchandise Store – Product Pricing & Catalog Configuration

- Can the client decide which product categories and products are hosted in their regional merchandise section?
- Can they define or customize the points value/redemption price or inflate prices for individual products based on their internal reward strategy?
