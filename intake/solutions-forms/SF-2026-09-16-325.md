## Solution Given
Product team is already working on it,below is the response from prod team:As you are aware, Dashboard V3 is currently in progress. As part of this revamp, the Overview section is being redesigned to provide an organisation-wide view, without country or department-level filters. The Overview will primarily support 90-day and 12-month time ranges.
For more granular analysis, including country and department-level filtering, the Analytics section will provide the required filter options.
We believe this updated dashboard structure should help address the client’s requirement from a reporting and visibility perspective.
Dashboard V3 is currently planned for rollout in October, with the final release date expected to be confirmed by the end of this month.
We will keep you posted once the release timeline is finalized.
