# Solution Request #321 - WCB Manitoba
**Date:** 2026-09-11  |  **Status:** Rejected  |  **Complexity:** Not Set

## Brief
Customization in Budget Report

## Problem Description
Hi Team,

We need your support in assessing the feasibility of a customization to the Budget Report for the WCB implementation.

As part of the current configuration, WCB has two independently tracked budget types:

Peer Budget: Individual budget available to all employees, including Reporting Managers (RMs), for Peer Awards.
Manager/Leader Budget: Budget allocated based on the RM’s Position Code, intended for awards to the RM’s direct reports. The budget remains associated with the Position Code if the manager changes.

The award nomination flow has been configured so that:

* All employees can view/use their Peer Budget when selecting a Peer Award.
* RMs can view/use their Peer Budget when selecting a Peer Award.
* RMs can view/use the Position Code-based Manager Budget only when selecting the applicable RM/Leader Award.

This configuration is now working as expected. However, WCB has a specific requirement for the consolidated Budget Report.

Reporting Requirement:

For the Manager/Leader Wallet records, WCB needs the Manager/RM Name to be populated alongside the Position Code in the same report record.

The Position Code must continue to be included because it is the technical identifier to which the Manager Budget is tied. However, the client does not want to manually cross-reference the Position Code to determine which manager the budget belongs to during reconciliation.

I have identified a way to populate the Manager/RM Name along with the Position Code in the report’s `Name` column, where the Position Code-based budget is currently displayed.** The expected format would therefore be something along the lines of:

Manager Name – Position Code

This would allow the client to identify the manager associated with the Position Code directly from the report without requiring a separate lookup.

Ideally, the consolidated report should provide the following fields(Not Exact):

Manager Name / Position Code | Opening Balance | Allocated Budget(Peer & RM) | Utilized Budget(Peer & RM) | Closing Balance | Wallet Type(Peer or RM)

For Peer Wallet records, the report should similarly include the employee name/ID along with the applicable financial fields.

The expected consolidated report would therefore contain both:

1. Peer Wallet records – Employee Name/ID + budget details + Wallet Type
2. Manager Wallet records – Manager Name + Position Code + budget details + Wallet Type

* Feasibility Confirmation

Could you please assess whether the above approach is technically feasible within the existing Budget Report customization framework?

Specifically, we would like to confirm whether the Manager/RM Name can be dynamically populated along with the corresponding Position Code in the Name column for the Position Code-based budget records.

The key requirement is that the report should clearly identify which manager is associated with each Position Code-based budget, without requiring the client to perform a separate lookup or VLOOKUP.

Please let us know if this can be supported and whether any additional fields or customization would be required.
