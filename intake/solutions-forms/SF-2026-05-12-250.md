# Solution Request #250 - Wipro
**Date:** 2026-05-12  |  **Status:** No Response Closed  |  **Complexity:** Not Set

## Subject
254250 : Solution Request : Wipro SYB requirements

## Brief
Wipro wants to introduce certain features/checks in current service year (LSA) process.

## Problem Description
Wipro wants to introduce certain features/checks in current service year (LSA) process. There are reminder emails which are sent to the employees to contribute for the citation. We have received multiple request that what if we want to stop the reminders after the first email for that particular employee. Continue to receive for other employees. 
Second- when employee forward the request to other employees to contribute for citation the client is requesting a bulk upload feature.

## Solution Given
1. Reminder Email Opt-Out Preference

Proposed Solution
We plan to add an option within the reminder email that allows users to stop receiving reminder emails for a specific employee’s yearbook.
The reminder email will include a link/message such as: “Disable Reminder Email for this Employee”
For example, if a user does not want reminders for Employee X’s yearbook, they can disable reminders only for that employee while continuing to receive reminders for other employees’ yearbooks.

2. Bulk Invitation Enhancement

Proposed Solution
Instead of uploading a CSV file, the proposed approach is to allow users to simply paste multiple email IDs directly into the invitation field.
The system will:
Validate the entered email IDs
Automatically add valid users to the self-invite process
