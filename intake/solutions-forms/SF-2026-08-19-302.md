# Solution Request #302 - Coromandel International
**Date:** 2026-08-19  |  **Status:** Open  |  **Complexity:** Not Set

## Brief
Automatic assignment of the Nominator/Approver role when an individual is designated as a Nominator or Approver through the Admin Dashboard.

## Problem Description
When a nominator or approver is assigned on the Admin dashboard, it is expected that the same role will be provided by the system automatically without accessing the site admin and assigning the roles separately. It has been observed that when we assign these roles on the dashboard, no roles are assigned by the system and one has to manually assign the nominator or the approver roles from the site admin. It is rquested to check the feasibility of the same of automatic assignment of the Nominator/Approver role when an individual is designated as a Nominator or Approver through the Admin Dashboard.
