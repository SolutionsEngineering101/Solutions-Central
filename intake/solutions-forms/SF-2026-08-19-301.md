# Solution Request #301 - Infosys
**Date:** 2026-08-19  |  **Status:** Unknown  |  **Complexity:** Not Set

## Subject
Solution Request : 301301 : Detailed Points statement for Infosys

## Brief
Request to Enable a More Detailed Points Statement for End Users

## Problem Description
Infosys is a redemption client with a points validity period of 13 months. Many times, we receive requests from users to extend their expired points, and as a result, the Support team manually extends the validity for 7 days.
However, in such cases, we receive queries from users as confusion arises regarding the expired points. The points statement available to users on the front end is in a standard format and does not clearly reflect points expiry and reinstatement scenarios. As a result, I have had to manually work on the report and share a detailed transaction history with the client, covering each instance from the first transaction to the latest one, including points expiry and points reinstatement scenarios. Only then were the client and the user able to gain clarity.
Based on such incidents, the client is requesting a more detailed points statement to be made available to end users so that they can get clarity themselves by referring to the statement available on the platform, without requiring our intervention.
