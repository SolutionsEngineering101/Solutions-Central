# Solution Request #295 - IBS Software
**Date:** 2026-08-11  |  **Status:** Open  |  **Complexity:** Not Set

## Subject
Solution Request : 294295 : IBS Software LSA Offline Voucher Automation

## Brief
Offline voucher process for IBS is taking a long time resulting in unnecessary delays & escalation

## Problem Description
Currently in LSA IBS employees can choose the GV which are processed offline. This process involves manual efforts from multiple people in our team. Nashreen, Aleeko, Accounts team, Rahul Saikia & Pinku. Can we streamline this process & try to automate this as much as possible

## Solution Given
The recommended approach is to use the existing Manager Gifting capability operated through a designated IBS user account with prepaid funds and a defined set of gift card denominations.

The proposed process would be straightforward:
Log in to the designated IBS user account that manages the gift card budget and open Manager Gifting.
Browse the available gift cards mapped for the company.
Select the preferred brand and gift card value.
Enter the recipient’s email address and, if required, add a personal message.
Review the selection, including the amount that will be deducted and the remaining budget.
Confirm the request.
