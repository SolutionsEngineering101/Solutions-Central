# Solution Request #291 - Agratas | Apollo Tyres
**Date:** 2026-08-03  |  **Status:** Unknown  |  **Complexity:** Not Set

## Subject
Solution request 290291::Quota balance check functionality for Admins in the Admin Dashboard

## Brief
Quota balance check functionality for Admins in the Admin Dashboard

## Problem Description
Hi Team,

We have received requests from multiple clients (e.g., Apollo Tyres and Agratas) for a Quota Balance check functionality within the Admin Dashboard, enabling administrators to view the available quota balance for individual quota holders directly from the platform.

Currently, administrators need to download the Quota Report each time they want to check a quota holder's balance. Additionally, the report may take up to a day to reflect the latest quota updates, resulting in delays and impacting the overall user experience. 

Additionally, only quota holders with approver roles are currently able to view their quota balance on the platform. Nominators who have been allocated quotas are unable to view their available quota balance from the homepage and can only see their remaining quota while submitting an award nomination.

It would be beneficial to extend quota balance visibility to all quota holders, irrespective of their role (nominator or approver), allowing them to view their available quota directly from the homepage or a dedicated section within the platform. This enhancement would improve transparency, reduce dependency on reports, and provide a more seamless user experience.

To address this, we request the addition of a Quota Balance Lookup feature in the Admin Dashboard. This enhancement will allow administrators to instantly view the current quota balance for any quota holder without relying on report downloads, thereby improving usability and providing a better experience for our clients.

To summarize, we would require assistance with the following enhancements:

1) Quota Balance Visibility for Nominators: Enable quota holders with the Nominator role to view their available quota balance on the left-hand panel of the platform, similar to the existing functionality available for quota holders with Approver roles.
2) Quota Balance check for Admins: Enable administrators to view the quota balance of any quota holder directly from the Admin Dashboard, eliminating the need to download quota reports for balance verification.

Please feel free to reach out if you need any further clarification or additional details.
