# Solution Request #343 - CloudKeeper
**Date:** 2026-10-07  |  **Status:** Pending Update  |  **Complexity:** Not Set

## Brief
API-first integration of Vantage Circle's rewards marketplace (redemption catalogue) into CloudKeeper's in-house R&R app.

## Problem Description
CloudKeeper (CK) is building its own R&R app to avoid vendor dependency and to make changes quickly without relying on a vendor. It does not want a full R&R platform. It needs Vantage Circle as a partner for a marketplace API that handles rewards redemption.

Key requirements and actions:

Expose the Vantage Circle marketplace via API so CK's in-house app can integrate seamlessly. The current model has employees redeem on a VC-hosted landing page, so the solutions team needs to confirm whether an embedded or white-labelled flow is possible.

Points-based model: 1 point = 1 INR (configurable).

Catalogs in scope:
1. Gift cards: 550+ options, with country-specific catalogs.
2. Amazon Store: in India, US and UK. Singapore employees must redeem Amazon gift cards instead.
3. Experiences: travel, stays and activities.
4. Milestone catalog: company-funded gifts for service anniversaries, unlocked automatically from tenure data.
5. Amazon Store requires full point payment (no co-pay). Experiences allows co-pay (points plus personal funds). CK's team needs to design around this.
6. Admin visibility into point allocation and redemption, plus human employee support through chat and email.
7. Employees are across India, Singapore, UK and US.
8. Deliverables from the VC side: API feasibility check with the solutions team, a marketplace demo login, and a commercial proposal (one-time setup fee plus any recurring maintenance or tech support costs).
9. CK's partner criteria: seamless API integration, a robust marketplace, and responsive post-service support.
