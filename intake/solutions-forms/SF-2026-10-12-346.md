# Solution Request #346 - MBRDI
**Date:** 2026-10-12  |  **Status:** Open  |  **Complexity:** Not Set

## Subject
Solution Request : 346346 : MBRDI New Requirements

## Brief
New requirements from MBRDI comp id 1681

## Problem Description
a) Pending status of any award for an exit user in the Employee points report or award nomination report to be changed to other status in report instead of keeping it in pending status for-ever. It can be mentioned as cancelled any other status which confirms that the award is cancelled due to exit user case.
                                                                                                                                                                b) Inactive Wallets email trigger check - For MBRDI, there are more than 40 department wallets from where the budget gets deducted whenever there is a nomination. we have observed a case recently where one of wallet was inactive in user table but active in employee table and it was highlighted to us by client after going through the consolidated budget report. Hence, client has requested that an email nudge or notification should be triggered to them whenever any wallet is inactive as it directly impacts the nomination flow.
                                                                                                                                                                c) Primary key - employee id for MBRDI. If there is an employee id change for any user with same email id in between nomination cycle, then that nomination should throw an error or stop that nomination rather than successfully getting that nomination approved in the new email id. For example- The employee was nominated for the Achievement of Excellence Award on 17 July 2026 under Employee ID INB00072744. However, the award remained pending approval at that time.

The old profile (INB00072744) was marked inactive, and a new active profile (INB00509518) with the same email address (tiwari.mahek_akhilesh@mercedes-benz.com) was created before the award was approved.

When the award was approved on 24 August 2026 by the approver, the system credited the points to the active profile (INB00509518). Since the email address remained the same and the old profile was inactive, the points were allocated to the new active account. Ideally the system should have given an error as employee ID is changing.
