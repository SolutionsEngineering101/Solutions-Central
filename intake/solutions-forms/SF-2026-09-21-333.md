## Subject
Solution Request : 333333 : SMS Holdings - Login & LSA Communication Requirement

## Brief
When we register the users on the platform, the welcome email (with username and password) needs to be suppressed but the username and password is to be noted as this needs to be printed in a letter from the CEO thanking the employee.

Each employee receives a presentation package of which this letter is a part of.
The congratulatory email on their day of LSA should go to the employee and their manager

## Problem Description
When we register the users on the platform, the welcome email (with username and password) needs to be suppressed but the username and password is to be noted as this needs to be printed in a letter from the CEO thanking the employee.

Each employee receives a presentation package of which this letter is a part of.
The congratulatory email on their day of LSA should go to the employee and their manager

## Solution Given
For this use case, we can enable email ID + OTP-based login for the employees. With this approach:
The standard welcome email containing the username and password can be suppressed.
Employees can log in using their registered email ID and will receive an OTP on their registered email address for authentication.
From a security standpoint, we would not be able to share or expose the employee's login credentials to an administrator for printing in the CEO's letter. Our platform architecture does not support an admin accessing or sharing individual user credentials.
For the LSA day communication, we can configure the congratulatory email to be sent to both the employee and their respective manager.
