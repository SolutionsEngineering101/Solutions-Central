# Solution Request #293 - Zeus Companies
**Date:** 2026-08-08  |  **Status:** Unknown  |  **Complexity:** Not Set

## Brief
1) Offline access and synchronization requirement for recognition. 
2) Kiosk based access for manufacturing/deskless employees

## Problem Description
Respondents should describe their standard approach for supporting users operating in environments with intermittent or limited network connectivity. Examples of relevant manufacturing use cases may include:
-       Shop-floor employees accessing the mobile application in production areas with poor Wi-Fi or cellular coverage.
-       Supervisors or managers issuing recognition while temporarily offline.
-       Kiosk or shared-device environments experiencing temporary connectivity interruptions.
-       Employees viewing previously loaded recognition activity, balances, or program information while offline.
-       Recognition transactions, nominations, approvals, or award submissions that can be captured offline and automatically synchronized once connectivity is restored.
-       Support for multi-shift operations where connectivity reliability varies by facility or location.
Vendors should specify:
-       Which platform functions are available offline.
-       Whether recognition submissions can be created and queued offline.
-       How synchronization occurs once connectivity is restored.
