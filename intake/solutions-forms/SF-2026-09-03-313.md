# Solution Request #313 - PISPL, ACG etc
**Date:** 2026-09-03  |  **Status:** Unknown  |  **Complexity:** Not Set

## Brief
Feasibility Check – Login via OTP Using Employee ID/Registered Phone Number

## Problem Description
The current Login via OTP feature enables triggering an OTP to the employee’s registered email ID.
However, for clients whose employees do not have corporate email IDs, particularly blue-collar employees, this creates a significant accessibility challenge.

Could you please check the feasibility of the following enhancement:

Requirement:

1. Allow employees to enter either their Employee ID or Registered Phone Number on the login screen.
2. Trigger the OTP to the employee’s registered phone number.
3. Allow the employee to authenticate and log in using the OTP received on their mobile.
4. Enable the feature for both web and app

This would help address a major platform accessibility challenge for blue-collar employees who do not have corporate email IDs. It would also significantly reduce dependency on the Support team for password resets and login-related assistance, thereby improving the overall user experience and adoption.
